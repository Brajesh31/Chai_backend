# Support

This repository is an educational project and does not currently offer a service-level support commitment.

## Questions and bug reports

Search existing issues first, then open a GitHub issue with a concise description, expected and observed behavior, relevant route or file, and safe reproduction steps. Include your Node.js and MongoDB versions when useful. Remove access tokens, passwords, personal data, and database connection strings from logs before posting.

For usage questions, explain what you are trying to do and which documented setup steps you followed. For a suspected vulnerability, do not use a public issue; follow [SECURITY.md](SECURITY.md).

## Scope

There is no guaranteed response time, compatibility promise, or hosted deployment support. See [CONTRIBUTING.md](CONTRIBUTING.md) if you want to propose a fix or documentation improvement.
